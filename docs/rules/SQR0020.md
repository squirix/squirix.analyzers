# SQR0020 - Merge duplicate catch blocks with identical bodies

<!-- sources -->
Sources: [MergeDuplicateCatchBlocksAnalyzer.cs](../../src/squirix.analyzers/MergeDuplicateCatchBlocksAnalyzer.cs)
<!-- sources -->

Consecutive `catch` blocks that catch different exception types with identical bodies should be combined into a single
`catch` clause with a `when` filter pattern. This keeps the duplicated handler body in one place.

Only clauses that declare an exception type, have no `when` filter, and do not reference their exception variable in the
body are considered, so the merge never changes behavior.

````csharp
// non-compliant
try
{
    Work();
}
catch (IOException)
{
    HandleFailure();
}
catch (ObjectDisposedException)
{
    HandleFailure();
}

// compliant
try
{
    Work();
}
catch (Exception ex) when (ex is IOException or ObjectDisposedException)
{
    HandleFailure();
}
````

Severity: **Warning**.
