# SQR0033 - Do not dereference a field outside the disposing branch of a finalizable Dispose(bool)

<!-- sources -->
Sources: [FinalizerDisposeFieldAnalyzer.cs](../../src/squirix.analyzers/FinalizerDisposeFieldAnalyzer.cs),
[DisposingPathGuards.cs](../../src/squirix.analyzers/DisposingPathGuards.cs)
<!-- sources -->

When a constructor throws, for example the base constructor, the object is already allocated and still gets
finalized. The constructor body did not run to the end, so the fields it assigns are still null. The finalizer calls
`Dispose(false)`, and a dereference of such a field throws `NullReferenceException` on the finalizer thread, which
terminates the process.

Nullable analysis does not see this: it treats a non-nullable field as assigned once the constructor ends. CA1063,
CA2215 and S3881 check only the shape of the dispose pattern.

The rule reports a dereference of an instance field in `Dispose(bool)` when all of these hold:

- the class declares a finalizer, or a base class declares one (for example `NetworkStream`) and the method is an
  override of `Dispose(bool)`;
- the field is declared in the same class, is not a value type (a reference type or an unconstrained type parameter)
  and has no initializer; it does not matter which constructor assigns it, or whether one does;
- the dereference is not on a guarded path (see below).

A dereference is a member access or call on the field (`_field.Member`, `_field.Method()`), an element access on an
array field, `foreach` over the field, `lock (_field)` and `await _field`. A dereference inside `finally` is reported
like any other.

## What is not reported

- A dereference inside a branch where `disposing` is true: `if (disposing) { ... }`, the `else` of
  `if (!disposing)`, the right side of `disposing && ...`, or the code after `if (!disposing) return;` (or `throw`).
  `disposing == true`, `disposing != false`, `disposing is true` and `disposing is not false` work the same way.
  `switch (disposing)` is not recognized.
- A null-guarded dereference: `_field?.Member`, `if (_field != null)`, `if (_field is not null)`, `_field is { ... }`,
  `_field != null && ...`, or the code after `if (_field is null) return;`. A pattern the rule cannot classify, and
  `ReferenceEquals(_field, null)`, are not treated as guards.
- A dereference guarded by a check of a flag: a value-type field that a constructor sets to something other than a
  `false`, `0`, `null` or `default` literal and that has no initializer, for example
  `if (Interlocked.Exchange(ref _tracked, 0) == 1)` where the constructor sets `_tracked = 1` after `base(...)`. The
  rule finds the assignment by field name in constructor bodies, outside object initializers, and does not see a flag
  set through `ref` (`Interlocked.Exchange(ref _tracked, 1)`). It does not verify the direction of a flag check.
- A dereference after an early exit applies only when the exit precedes it in the same block or an enclosing one; a
  `return` inside `try` does not guard the `finally`.
- A field with an initializer: initializers run before the base constructor.
- A class without a finalizer, own or inherited.
- Value-type and static fields, fields of a base class, properties, and dereferences inside lambdas, local functions
  and `nameof`.
- Extension method calls on the field, which receive it as an argument.
- Indirect dereferences: a local copy (`var g = _gate; g.Exit();`), the result of
  `Interlocked.Exchange(ref _gate, null).Exit()`, `throw _exception;`, a field-like event invoked as `Changed()`, and
  fields dereferenced in methods that `Dispose(bool)` calls.

```csharp
// non-compliant
protected override void Dispose(bool disposing)
{
    base.Dispose(disposing);
    _connections.Exit();
}

// compliant: the constructor sets _tracked after base(...), so a half-built object releases nothing
protected override void Dispose(bool disposing)
{
    try
    {
        base.Dispose(disposing);
    }
    finally
    {
        if (Interlocked.Exchange(ref _tracked, 0) == 1)
            _connections.Exit();
    }
}
```

Severity: **Warning**.
