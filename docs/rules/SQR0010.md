# SQR0010 - Omit braces from single-line single-statement body

<!-- sources -->
Sources: [OmitSingleStatementBracesAnalyzer.cs](../../src/squirix.analyzers/OmitSingleStatementBracesAnalyzer.cs)
<!-- sources -->

Omit braces when a control-flow body is a single single-line statement. Keep braces for multiline bodies and for if/else
chains with a multi-statement branch.

````csharp
// non-compliant
if (ready)
{
    Run();
}

// compliant
if (ready)
    Run();

// compliant: multiline body keeps braces
if (ready)
{
    Run()
        .Continue();
}
````

Braces are kept, and no diagnostic is reported, when removing them would change meaning or not compile:

- the braced statement is, or ends in, an `if` without `else` (also through nested `while`, `for`, `foreach`, `using`,
  `lock`, `fixed` tails) while the enclosing `if` has an `else`, because the `else` would re-bind to the inner `if`;
- the single statement is a local declaration, local function, or labeled statement, which are not valid embedded
  statements;
- the block contains preprocessor directives.

Applies to `if`/`else`, `for`, `foreach`, `while`, `do`, `using`, `lock`, and `fixed` statements. Nested-loop outer
braces are handled by SQR0001.

Severity: **Warning**.
