# SQR0010 - Omit braces from single-line single-statement body

<!-- sources -->
Sources: [OmitSingleStatementBracesAnalyzer.cs](../../src/squirix.analyzers/OmitSingleStatementBracesAnalyzer.cs)
<!-- sources -->

Omit braces when a control-flow body is a single single-line statement. Keep braces for multiline bodies and for if/else
chains with a multi-statement branch.

````csharp
// non-compliant
if (ready)
{
    Run();
}

// compliant
if (ready)
    Run();

// compliant: multiline body keeps braces
if (ready)
{
    Run()
        .Continue();
}
````

Applies to `if`/`else`, `for`, `foreach`, `while`, `do`, `using`, `lock`, and `fixed` statements. Nested-loop outer
braces are handled by SQR0001.

Severity: **Warning**.
