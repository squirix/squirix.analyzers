# SQR0012 - Prefer '==' / '!=' over 'is' / 'is not' for null checks

<!-- sources -->
Sources: [PreferEqualityOperatorAnalyzer.cs](../../src/squirix.analyzers/PreferEqualityOperatorAnalyzer.cs)
<!-- sources -->

Prefer the equality operators for null checks; `x == null` and `x != null` read more clearly than `x is null` and
`x is not null`.

The rule only fires when the expression's type resolves to a built-in null operator (reference type or nullable value
type that does not define user-defined equality operators).

````csharp
// non-compliant
if (value is null)
    return;
if (value is not null)
    return;

// compliant
if (value == null)
    return;
if (value != null)
    return;
````

Severity: **Info**.
