# SQR0028 - Pass large readonly structs by 'in'

A struct passed by value is copied for every call: into registers when it is small, and otherwise to memory the
callee reads through a pointer. The copy grows with the struct. A `readonly` struct can be passed by `in` instead:
the callee gets a reference, and because every member of a readonly struct is readonly, reading through that
reference never forces a hidden copy.

The rule reports a by-value parameter of a method, constructor, operator or conversion operator when its type is a
`readonly struct` larger than the limit.

## What `in` changes

An `in` parameter is a reference to the caller's variable, not a snapshot of it. If that variable is reassigned
while the method runs, by the method itself or by another thread, the method sees the new value:

```csharp
private void Update(in Measurement previous)
{
    _current = Compute();   // when the caller passed _current, previous now reads the new value
    Log(previous.Count);
}
```

Before applying the fix, check what callers pass. A local, a parameter or a temporary value is safe. A field or an
array element is safe only when nothing can write it during the call; otherwise copy it to a local at the call site
or keep the parameter by value and suppress the diagnostic.

Changing a public method to `in` is a binary breaking change for assemblies compiled against the old signature.

## What is not reported

- the method is `async` or an iterator;
- the method is an override, an interface member, or implements an interface member, so its signature is fixed
  elsewhere;
- the declaration has no body (abstract, extern and partial definitions);
- the parameter is assigned, passed by `ref` or `out`, has its address taken, or is captured by a lambda or a local
  function, in the body or in a constructor initializer;
- the method returns a ref struct or returns by reference, or is a ref struct constructor: with `in` the result
  could capture the parameter and callers would stop compiling (`scoped in` is the fix there);
- an overload takes the same parameter by reference, or the method is marked `[UnmanagedCallersOnly]`;
- the method is used as a method group (`items.Select(Sum)`, `Changed += OnChanged`, `&Handle`) anywhere in its
  outermost type or in a type nested there, generated parts included: the delegate type fixes the signature, and
  `in` would stop the code compiling. An override used that way protects the method it overrides. In another file of
  a partial type, any mention of that name outside a call or `nameof` counts as such a use, even when it names
  something else;
- the parameter is `params`;
- the struct is not `readonly`: passing a mutable struct by `in` trades one copy for a hidden copy on every member
  call.

Local functions, lambdas, indexers, delegates and primary constructors are not analyzed.

Two cases cannot be seen from the declaration, so check them when applying the fix: a method that another type
converts to a delegate or function pointer must keep the parameter modifiers of that delegate type, and a base-class
method that a derived class uses to implement an interface must keep the interface signature.

## How size is estimated

Sizes are computed for a 64-bit runtime. Fields keep their declaration order with natural alignment, unless the
struct holds object references: the runtime reorders those to remove padding. `[StructLayout]` with `Pack`, `Size`
or `LayoutKind.Explicit` and `[FieldOffset]`, fixed-size buffers and `[InlineArray]` are honored for structs
declared in source.

Nothing is reported when the layout cannot be seen: a type parameter, a framework struct whose reference assembly
hides its fields (a few common ones such as `Guid`, `TimeSpan` and `Memory<T>` are known by name), and anything
built from them. An explicit layout declared in another assembly is not visible either, so such a struct is sized
as if its fields did not overlap.

The limit is the `SQR0028.max_by_value_size` `.editorconfig` option (default 16 bytes).

```csharp
readonly struct Measurement { public readonly long Start, End, Count; }

// non-compliant
long Duration(Measurement value) => value.End - value.Start;

// compliant
long Duration(in Measurement value) => value.End - value.Start;
```

Severity: **Warning**.
