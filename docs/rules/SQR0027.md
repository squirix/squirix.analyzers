# SQR0027 - Set DisposeHttpClient when GrpcChannelOptions receives an owned handler or client

<!-- sources -->
Sources: [GrpcDisposeHttpClientAnalyzer.cs](../../src/squirix.analyzers/GrpcDisposeHttpClientAnalyzer.cs)
<!-- sources -->

`GrpcChannel` disposes the handler or client passed through `GrpcChannelOptions.HttpHandler` or
`GrpcChannelOptions.HttpClient` only when `DisposeHttpClient` is `true`, and that flag defaults to `false`. A handler
created for one channel and passed without the flag leaks its connection pools and HTTP/2 and TLS sessions after the
channel is disposed. `CA2000` treats assigning to a property of another object as an ownership transfer, and `CA2213`
only inspects the type's own disposable fields, so neither reports this.

The rule reports an object initializer or property assignment on `Grpc.Net.Client.GrpcChannelOptions` that sets
`HttpHandler` or `HttpClient` to a newly created disposable (`new SocketsHttpHandler()`), to the result of a factory
call, or to a local variable initialized that way, when `DisposeHttpClient` is not set for the same options object.

Nothing is reported when `DisposeHttpClient` is assigned any value, constant or expression, because the ownership
decision is then explicit. That covers the same initializer, an initializer that creates the options object
(`var options = new GrpcChannelOptions { DisposeHttpClient = true };` or the same form in a later assignment to the
variable) followed by a separate `HttpHandler` assignment, and an assignment for the same options object anywhere in
the same member. In top-level statements the whole file's statements are searched. A handler or client held in a
parameter or field is owned by the caller or the type and is not reported, and neither is a local declared with
`using` or `await using`, because the scope already disposes it and `DisposeHttpClient = true` would dispose it twice.

```csharp
// non-compliant
var options = new GrpcChannelOptions { HttpHandler = new SocketsHttpHandler() };

// compliant
var options = new GrpcChannelOptions { HttpHandler = new SocketsHttpHandler(), DisposeHttpClient = true };
```

Severity: **Warning**.
