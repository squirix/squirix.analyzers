# SQR0025 - Try-prefixed method must return a Boolean result

<!-- sources -->
Sources: [TryPrefixMustReturnBoolAnalyzer.cs](../../src/squirix.analyzers/TryPrefixMustReturnBoolAnalyzer.cs)
<!-- sources -->

Methods prefixed with `Try` must return `bool`, `Task<bool>`, or `ValueTask<bool>`. This keeps the `Try` naming
convention honest: callers can rely on the boolean outcome, including from asynchronous methods.

Override methods are ignored: their names are dictated by the base declaration (for example a generated gRPC
contract), which is flagged instead.

Interface implementations (implicit and explicit) are ignored for the same reason; the interface declaration itself is
flagged.

`Try` is matched as a whole word: the name must be exactly `Try` or continue with a character that is not a lowercase
letter (`TryParse`, `Try1`, `Try_x` are checked; `Tryout` is not).

```csharp
// non-compliant
public Task<int> TryGetAsync() => Task.FromResult(0);

// compliant
public bool TryParse(string s, out int result) => int.TryParse(s, out result);

// compliant
public Task<bool> TryPingAsync() => Task.FromResult(true);
```

Severity: **Warning**.
