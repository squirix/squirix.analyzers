# SQR0004 - Avoid types with name too long

<!-- sources -->
Sources: [TypeNameTooLongAnalyzer.cs](../../src/squirix.analyzers/TypeNameTooLongAnalyzer.cs)
<!-- sources -->

Type simple names must be at most 40 characters. Long type names hurt readability and line width; prefer a shorter name
or split the responsibility.

````csharp
// non-compliant: simple name longer than 40 characters
class ThisIsAnExtremelyLongTypeNameThatExceedsTheFortyCharacterLimit { }

// compliant
class ConfigurationSnapshot { }
````

Severity: **Info**.
