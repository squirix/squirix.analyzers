# SQR0009 - Avoid redundant named arguments

<!-- sources -->
Sources: [RedundantNamedArgumentAnalyzer.cs](../../src/squirix.analyzers/RedundantNamedArgumentAnalyzer.cs)
<!-- sources -->

Prefer positional arguments; omit argument names when the call uses parameters in declaration order. Named arguments that
do not reorder or skip parameters are redundant noise.

````csharp
// non-compliant
var result = Compute(left: 1, right: 2, mode: Mode.Fast);

// compliant
var result = Compute(1, 2, Mode.Fast);

// compliant: named arguments are required when reordering or skipping
var result = Compute(right: 2, left: 1);
````

Applies to method invocations and object creations (including target-typed `new`).

Severity: **Info**.
