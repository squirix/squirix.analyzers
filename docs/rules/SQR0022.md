# SQR0022 - Prefer ArgumentOutOfRangeException throw helpers for TimeSpan guards

<!-- sources -->
Sources: [UseTimeSpanThrowHelperAnalyzer.cs](../../src/squirix.analyzers/UseTimeSpanThrowHelperAnalyzer.cs)
<!-- sources -->

Guards that compare a value against `TimeSpan.Zero` and throw `ArgumentOutOfRangeException` should use one of the
`ArgumentOutOfRangeException.ThrowIf*` helpers instead. The helper keeps the throwing path out of the caller, which
keeps the caller small and inlineable.

Numeric-constant comparisons are CA1512 territory and are not flagged here; only `TimeSpan.Zero` comparisons, which
CA1512 does not recognize, are considered. `switch` arms cannot use a throw helper and are never flagged.

```csharp
// non-compliant
if (value <= TimeSpan.Zero)
    throw new ArgumentOutOfRangeException(nameof(value), value, "Must be positive.");

// compliant
ArgumentOutOfRangeException.ThrowIfNegativeOrZero(value);
```

Severity: **Info** (escalate to `warning`/`error` in the consuming repository once the codebase is migrated).
