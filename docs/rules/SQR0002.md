# SQR0002 - Avoid types with too many methods

<!-- sources -->
Sources: [TooManyMethodsAnalyzer.cs](../../src/squirix.analyzers/TooManyMethodsAnalyzer.cs)
<!-- sources -->

Types with more than 20 instance or static methods tend to have too many responsibilities. Split the type into
collaborators, each owning a focused concern.

`constructors`, property accessors, and event accessors are not counted. Stateless types that only hold constants are not
matched.

## Configuration

The method limit defaults to `20` and can be overridden per project in `.editorconfig`:

```editorconfig
# .editorconfig
SQR0002.max_methods_per_type = 25
```

````csharp
// non-compliant: more than 20 ordinary/operator/conversion methods
class ConfigurationManager
{
    public void Load() { }
    public void Save() { }
    // ... 19 more behavior methods
}

// compliant: responsibilities moved to focused collaborators
class ConfigurationLoader
{
    public void Load() { }
}

class ConfigurationSaver
{
    public void Save() { }
}
````

Severity: **Info**.
