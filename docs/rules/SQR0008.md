# SQR0008 - Add braces to multiline embedded loop body

<!-- sources -->
Sources: [RequireMultilineLoopBodyBracesAnalyzer.cs](../../src/squirix.analyzers/RequireMultilineLoopBodyBracesAnalyzer.cs)
<!-- sources -->

When a loop body is a single embedded statement that spans multiple lines, add braces around the body. Without braces a
multiline embedded statement is easy to misread. Nested loops alone are exempt (handled by SQR0001).

````csharp
// non-compliant: embedded statement spans multiple lines without braces
while (condition)
    DoSomething()
        .ThenSomethingElse();

// compliant
while (condition)
{
    DoSomething()
        .ThenSomethingElse();
}
````

Applies to `for`, `foreach`, `while`, and `do` loops.

Severity: **Warning**.
