# SQR0015 - Dispose guard must be an int flag toggled with Interlocked

<!-- sources -->
Sources: [NoBoolDisposedFieldAnalyzer.cs](../../src/squirix.analyzers/NoBoolDisposedFieldAnalyzer.cs)
<!-- sources -->

A disposure guard must be an `int` flag, never a plain `bool` field. A `bool _disposed` field is not thread-safe.

Squirix requires the dispose guard to be an `int` field mutated via `System.Threading.Interlocked` and observed via
`System.Threading.Volatile`.

````csharp
// non-compliant
private bool _disposed;

// compliant
private int _disposed;
````

Companion rule SQR0016 requires the guard to be accessed only through `Interlocked` / `Volatile`.

Severity: **Warning**.
