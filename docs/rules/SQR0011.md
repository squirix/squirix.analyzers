# SQR0011 - Avoid redundant default argument values

<!-- sources -->
Sources: [RedundantDefaultArgumentAnalyzer.cs](../../src/squirix.analyzers/RedundantDefaultArgumentAnalyzer.cs)
<!-- sources -->

Omit arguments that equal the parameter default. Passing the default explicitly is redundant, and the default may change
at the declaration — keeping it implicit makes the call robust to such changes.

````csharp
public void Configure(int retries = 3, bool failFast = false) { }

// non-compliant
Configure(retries: 3, failFast: false);

// compliant
Configure();
````

The rule only reports when the argument can be dropped without changing which method is bound, and (for positional
arguments) when every later positional argument is also a redundant default.

Severity: **Info**.
