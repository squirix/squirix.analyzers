# SQR0014 - Prefer '!=' over 'is not' for constant values

<!-- sources -->
Sources: [PreferEqualityOperatorAnalyzer.cs](../../src/squirix.analyzers/PreferEqualityOperatorAnalyzer.cs)
<!-- sources -->

Constant-value inequality reads more clearly with the `!=` operator than with an `is not` pattern. Prefer `x != constant`
over `x is not constant`.

The rule does not fire for `float.NaN` / `double.NaN`, because equality operators never match NaN while constant
patterns do.

````csharp
// non-compliant
if (status is not 200)
    return;

// compliant
if (status != 200)
    return;
````

Severity: **Info**.
