# SQR0040 - Do not keep a logger in static state

<!-- sources -->
Sources: [NoStaticLoggerAnalyzer.cs](../../src/squirix.analyzers/NoStaticLoggerAnalyzer.cs)
<!-- sources -->

A logger in a static field or property is shared by every user of the type and is set outside its constructor.
Nothing in the type's signature shows that it logs, and its logs go wherever the last assignment pointed.

The rule reports a static field or property whose type is `ILogger`, `ILogger<T>` or `ILoggerFactory`, or a type that
implements one of them.

Not reported: a logger type that exposes its own singleton, such as `NullLogger.Instance`.

````csharp
// non-compliant
static class Logging
{
    public static ILoggerFactory? Factory { get; set; }
}

class Worker
{
    private static readonly ILogger Log = Logging.Factory!.CreateLogger("worker");
}

// compliant
class Worker
{
    private readonly ILogger<Worker> _log;

    public Worker(ILogger<Worker> log)
    {
        _log = log;
    }
}
````

Severity: **Warning**.
