# SQR0031 - Unwrap nested tasks before awaiting or returning them

<!-- sources -->
Sources: [NestedTaskAnalyzer.cs](../../src/squirix.analyzers/NestedTaskAnalyzer.cs)
<!-- sources -->

A nested task is a `Task<X>` or `ValueTask<X>` whose result type `X` is itself a `Task`, `Task<T>`, `ValueTask` or
`ValueTask<T>`. The usual source is `Task.Factory.StartNew(async () => ...)` or `StartNew(() => SomeAsync())`:
`StartNew` does not unwrap the delegate's task. The outer task completes as soon as the delegate returns the inner
task, so awaiting the outer task does not wait for the inner work and an exception of the inner task is never
observed.

The rule reports a nested task in two shapes:

- an `await` whose result is discarded, either an expression statement (`await nested;`) or `_ = await nested;`,
  also through `.ConfigureAwait(...)`;
- an implicit conversion of a `Task<X>` nested task to `Task`: a local or field typed `Task`, a `return` in a
  `Task`-returning method or lambda, an argument for a `Task` parameter (including the elements of
  `Task.WhenAll(params Task[])`), and array or collection elements typed `Task`.

## Fixes

- Call `Unwrap()` on the nested task: `Task.Factory.StartNew(async () => ...).Unwrap()` returns a task that
  completes with the inner task.
- Use `Task.Run`, which unwraps the delegate's task itself.
- Await twice: `await await nested;` or `var inner = await nested; await inner;`.

## What is not reported

- A nested task after `Unwrap()`, because its type is no longer nested.
- `await await nested` and an awaited result that is stored or otherwise used.
- `Task.Run(async () => ...)`, which returns an unwrapped task.
- An explicit cast such as `(Task)nested`, which is treated as intentional.
- Custom awaitables that are not `Task` or `ValueTask`, for example an extension `GetAwaiter` on a tuple of tasks.

```csharp
// non-compliant
await Task.Factory.StartNew(async () => await DoWorkAsync());

// compliant
await Task.Factory.StartNew(async () => await DoWorkAsync()).Unwrap();
await Task.Run(async () => await DoWorkAsync());
```

Severity: **Warning**.
