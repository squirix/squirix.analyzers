# SQR0005 - Avoid methods with name too long

<!-- sources -->
Sources: [MethodNameTooLongAnalyzer.cs](../../src/squirix.analyzers/MethodNameTooLongAnalyzer.cs)
<!-- sources -->

Method simple names must be at most 40 characters. Long method names hurt readability; prefer a shorter name or split
the behavior.

Property accessors subtract the `get_` / `set_` prefix before measuring. Explicit interface implementations are excluded.

````csharp
// non-compliant: simple name longer than 40 characters
void PrepareTheBatchForSubsequentRetryAfterTheTransientFailureOccurs() { }

// compliant
void PrepareBatchForRetry() { }
````

Severity: **Info**.
