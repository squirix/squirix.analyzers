# SQR0005 - Avoid methods with name too long

<!-- sources -->
Sources: [MethodNameTooLongAnalyzer.cs](../../src/squirix.analyzers/MethodNameTooLongAnalyzer.cs)
<!-- sources -->

Method, property, and event simple names must be at most 40 characters. Long names hurt readability; prefer a shorter
name or split the behavior.

Properties and events are measured by their own name and reported once; accessor methods (`get_`, `set_`, `init_`,
`add_`, `remove_`) are not reported separately, so the accessor prefix never counts toward the limit. Overrides and
interface implementations (implicit and explicit) are excluded because the base declaration decides the name. Local
functions and lambdas are not checked.

````csharp
// non-compliant: simple name longer than 40 characters
void PrepareTheBatchForSubsequentRetryAfterTheTransientFailureOccurs() { }

// compliant
void PrepareBatchForRetry() { }
````

Severity: **Info**.
