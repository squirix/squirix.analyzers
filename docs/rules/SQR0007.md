# SQR0007 - Avoid type names that repeat the parent namespace segment

<!-- sources -->
Sources: [TypeNamespacePrefixAnalyzer.cs](../../src/squirix.analyzers/TypeNamespacePrefixAnalyzer.cs)
<!-- sources -->

Type simple names must not start with the immediate parent namespace segment. Repeating the leaf namespace segment is
redundant because the type is already qualified by its namespace.

The check requires a PascalCase boundary: the name starts with the segment and is followed by an uppercase letter (or is
an exact match).

````csharp
// non-compliant: type name repeats the namespace segment "Persistence"
namespace Squirix.Storage.Persistence;

class PersistenceJournal { }

// compliant
namespace Squirix.Storage.Persistence;

class Journal { }
````

Severity: **Info**.
