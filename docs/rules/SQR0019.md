# SQR0019 - Avoid allocating xUnit Throws assertions

<!-- sources -->
Sources: [NoAllocatingXunitThrowsAssertAnalyzer.cs](../../src/squirix.analyzers/NoAllocatingXunitThrowsAssertAnalyzer.cs)
<!-- sources -->

xUnit `Throws` assertions capture a delegate display class on every call, allocating on the hot path. Avoid them in
allocation-sensitive test code.

Prefer the testkit's allocation-free assertions: `NodeExceptionAssert.For<TException>().Throws(...)` for synchronous
throws, and `NodeAsyncAssert.ThrowsAsync<TException>(...)` (or `ThrowsAnyAsync`) for asynchronous throws.

````csharp
// non-compliant: allocating assert that captures the delegate
Assert.Throws<InvalidOperationException>(() => operation());

// compliant: pass the already-started task instead of wrapping a delegate
await NodeAsyncAssert.ThrowsAsync<InvalidOperationException>(operationAsync());
````

Severity: **Warning**.
