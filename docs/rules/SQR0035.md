# SQR0035 - Avoid primary constructors on classes and structs

<!-- sources -->
Sources: [NoPrimaryConstructorAnalyzer.cs](../../src/squirix.analyzers/NoPrimaryConstructorAnalyzer.cs)
<!-- sources -->

Classes and structs declare explicit constructors. A primary constructor parameter that an instance member uses is
captured implicitly: it then acts like a mutable field that has no declaration.

The rule matches a parameter list on a `class` or `struct` declaration. Records are not matched: their primary
constructor is the type's defining shape.

````csharp
// non-compliant
class Cache(int capacity)
{
    public int Capacity => capacity;
}

// compliant
class Cache
{
    private readonly int _capacity;

    public Cache(int capacity)
    {
        _capacity = capacity;
    }

    public int Capacity => _capacity;
}
````

Severity: **Warning**.
