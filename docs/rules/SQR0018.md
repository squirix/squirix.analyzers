# SQR0018 - Add braces to multiline embedded if/else body

<!-- sources -->
Sources: [RequireMultilineIfBodyBracesAnalyzer.cs](../../src/squirix.analyzers/RequireMultilineIfBodyBracesAnalyzer.cs)
<!-- sources -->

When an `if` / `else if` / `else` body is a single embedded statement that spans multiple lines, add braces around the
body. Without braces a multiline embedded statement is easy to misread; this mirrors SQR0008 for loops.

````csharp
// non-compliant: embedded statement spans multiple lines without braces
if (condition)
    DoSomething()
        .ThenSomethingElse();

// compliant
if (condition)
{
    DoSomething()
        .ThenSomethingElse();
}
````

A nested `if` without an `else` is exempt as a body: it is checked as an `if` of its own, so the braces are asked for at
the statement that spans the lines. A nested `if` that has an `else` is not exempt, because without braces it is easy to
misread which `if` the `else` belongs to:

````csharp
// non-compliant: the else belongs to the inner if
if (condition)
    if (other)
        DoSomething();
    else
        DoSomethingElse();

// compliant
if (condition)
{
    if (other)
        DoSomething();
    else
        DoSomethingElse();
}
````

The diagnostic sits on the nested `if`; the braces go around the whole nested `if`/`else`. A nested `if`/`else` written
on one line is not reported.

Severity: **Warning**.
