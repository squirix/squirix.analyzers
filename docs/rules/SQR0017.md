# SQR0017 - Avoid reading the cancellation token from TestContext.Current

<!-- sources -->
Sources: [NoDirectTestContextCancelTokenAnalyzer.cs](../../src/squirix.analyzers/NoDirectTestContextCancelTokenAnalyzer.cs)
<!-- sources -->

Tests must not read the test cancellation token from `TestContext.Current`. The rule knows two test frameworks and
gives each its own advice. `TestContext` is matched by type (`TUnit.Core.TestContext`, `Xunit.TestContext`), so an
unrelated class with the same name is not reported.

In both cases the access is also reported when written with the null-forgiving operator, the null-conditional
operator, parentheses, or a qualified name. Other members of `TestContext.Current` (for example `Id`) and a token read
from a local that holds the context are not matched.

## TUnit

`TestContext.Current.Execution.CancellationToken` is always reported. TUnit passes the token to a test method or hook
that declares a `CancellationToken` parameter; take that parameter and pass it down to helpers.

````csharp
// non-compliant
[Test]
public async Task Reads()
{
    await client.GetAsync("key", TestContext.Current!.Execution.CancellationToken);
}

// compliant
[Test]
public async Task Reads(CancellationToken cancellationToken)
{
    await client.GetAsync("key", cancellationToken);
}
````

## xUnit v3

`TestContext.Current.CancellationToken` must not be consumed directly inside a non-static class unless that class or
one of its base classes exposes a shared `CancellationToken` member. Consume the shared token exposed by the (base)
test class instead, so tests do not access TestContext directly everywhere.

The member is matched by type (`System.Threading.CancellationToken`), not by name, so its name is left up to you.

Static classes cannot derive from a shared test base, so they are not matched.

````csharp
// non-compliant: no base class exposes a shared CancellationToken member
class SomeTest
{
    public void TestAsync()
    {
        var token = TestContext.Current.CancellationToken;
    }
}

// compliant: the base test class exposes a shared token
class TestBase
{
    protected System.Threading.CancellationToken TestToken
        => TestContext.Current.CancellationToken;
}

class DerivedTest : TestBase
{
    public void TestAsync()
    {
        var token = TestToken;
    }
}
````
