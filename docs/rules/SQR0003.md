# SQR0003 - Avoid types with too many fields

<!-- sources -->
Sources: [TooManyFieldsAnalyzer.cs](../../src/squirix.analyzers/TooManyFieldsAnalyzer.cs)
<!-- sources -->

Types with more than 15 non-literal, non-`static readonly` fields tend to hold too much state. Split the state or
introduce collaborators.

Constants (`const`) and `static readonly` fields are not counted.

## Configuration

The field limit defaults to `15` and can be overridden per project in `.editorconfig`:

```editorconfig
# .editorconfig
SQR0003.max_fields_per_type = 10
```

````csharp
// non-compliant: more than 15 counted instance fields
class SessionState
{
    private int _a; private int _b; private int _c;
    // ... 16+ mutable instance fields
}

// compliant: state grouped into focused collaborators
class SessionState
{
    private readonly ConnectionState _connection;
    private readonly AuthenticationState _authentication;
}
````

Severity: **Info**.
