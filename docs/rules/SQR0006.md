# SQR0006 - Avoid fields with name too long

<!-- sources -->
Sources: [FieldNameTooLongAnalyzer.cs](../../src/squirix.analyzers/FieldNameTooLongAnalyzer.cs)
<!-- sources -->

Field names must be at most 40 characters. Long field names hurt readability; prefer a shorter, descriptive name.

````csharp
// non-compliant: field name longer than 40 characters
private int _numberOfConsecutiveSuccessfulRetryAttemptsBeforeFailure;

// compliant
private int _successfulRetryCount;
````

Severity: **Info**.
