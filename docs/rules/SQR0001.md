# SQR0001 - Omit braces from outer loop that only contains a nested loop

<!-- sources -->
Sources: [OmitOuterLoopBracesAnalyzer.cs](../../src/squirix.analyzers/OmitOuterLoopBracesAnalyzer.cs)
<!-- sources -->

When an outer loop's body consists only of a nested loop (no other statements), the outer braces are redundant and must be
omitted.

````csharp
// non-compliant
for (var i = 0; i < n; i++)
{
    for (var j = 0; j < m; j++)
    {
        Process(i, j);
    }
}

// compliant
for (var i = 0; i < n; i++)
    for (var j = 0; j < m; j++)
        Process(i, j);
````

Applies to `for`, `foreach`, `while`, and `do` loops. The rule only fires when the outer block contains exactly one
statement and that statement is itself a loop.

The braces are kept, and nothing is reported, when removing them would change what the code means:

- the block contains a preprocessor directive, so its content depends on the defined symbols;
- an `else` follows the loop and the nested loop ends in an `if` without its own `else`, which would capture it.

````csharp
// compliant: without the braces the else would bind to 'if (y > 0)'
if (ready)
    while (running) { foreach (var y in ys) if (y > 0) Log(); }
else
    Log();
````

Severity: **Warning**.
